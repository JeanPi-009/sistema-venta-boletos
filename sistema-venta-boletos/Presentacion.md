# 🎟️ Sistema de Venta de Boletos para Eventos

Proyecto web desarrollado para la gestión y compra de boletos de eventos deportivos.

##  Descripción del Proyecto

Este sistema permite a los usuarios:

- Registrarse en la plataforma
- Iniciar sesión
- Completar su información personal
- Visualizar eventos disponibles
- Agregar boletos al carrito
- Simular una compra

Todo desarrollado con tecnologías web básicas:
- HTML
- CSS
- JavaScript
